## 8. 회원가입 / 로그인

- 로그인: 이메일+비밀번호(ID 저장·로그인 유지), 간편비밀번호 6자리, 앱으로 로그인(딥링크), ID/PW 찾기. 소셜 로그인·공동인증서 없음
- 회원가입(투자자): 개인 3단계/법인 4단계 — 유형·이메일·비밀번호·추천인·약관 → PASS 본인인증 + 간편비밀번호 등록 → 완료 → 연결계좌 등록
- 회원가입(대출자): 신용정보 조회 동의 추가
- 등급 선택은 가입 단계에 없음 → 가입 후 등급 변경 신청으로 취득
