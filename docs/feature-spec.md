## F-AUTH 회원·인증

### F-AUTH-01 회원가입 (투자자)

| 항목 | 내용 |
|---|---|
| 설명 | 투자자 계정 생성. 3단계 위저드 |
| 입력 | 1단계: 이메일 ID(중복 불가, 도메인 퀵선택)·비밀번호(영문+숫자+특수문자 8~15자)·비밀번호 재입력·추천인 이메일(선택)·약관 동의(필수 5종+선택 3종) / 2단계: 본인인증(모의) / 3단계: 간편비밀번호 6자리 등록 |
| 검증 | 이메일 형식·중복 검사, 비밀번호 정책, 필수 약관 전체 동의, 추천인 이메일 존재 시 포인트 적립 큐 |
| 완료 | 계정 생성 + 가상계좌 발급(F-DEP-01) + 완료 화면 → 연결계좌 등록 유도 |
| 비고 | 법인 가입 4단계(법인명·법인등록번호·사업자번호·대표자 정보)는 선택 구현 |

### F-AUTH-02 회원가입 (대출자)

- 투자자와 별도 가입 경로. 개인(신용)정보 조회 동의·온라인연계대출약관 추가
- 완료 시 "연결계좌 등록" 필요 안내

### F-AUTH-03 로그인 / 로그아웃

- 이메일 + 비밀번호, ID 저장·로그인 유지 옵션
- 간편비밀번호 6자리 로그인(앱에서는 네이티브 키패드 화면, 웹은 화면 키패드), 5회 실패 시 잠금
- 앱으로 로그인: 앱이 발급한 일회용 코드를 웹 로그인 화면에 입력(실서비스의 앱 딥링크 로그인 모사)
- 앱에서는 생체인증(FaceID/지문)으로 잠금 해제 — 브릿지로 세션 복원
- 아이디 찾기(SMS 모의), 비밀번호 재설정(이메일 링크 모의)

### F-AUTH-04 본인인증 (모의)

- PASS 흐름 모사: 통신사 선택 → 이름·생년월일·휴대폰 입력 → 모의 인증 번호 → CI 값 발급
- 실제 통신사 연동 없이 서버가 인증 결과를 생성. 중복 CI 가입 차단 로직은 실구현

### F-AUTH-05 2차 인증 게이트

- 회원정보 변경·계좌관리·출금·등급 변경 신청 전 비밀번호 재확인
- 통과 시 짧은 수명의 인증 토큰 발급(10분)

## F-INV 투자

### F-INV-01 투자 상품 목록

| 항목 | 내용 |
|---|---|
| 화면 | `/investment` |
| 필터 | 모집 상태(전체/모집중/모집예정), 수익률 정렬(낮은 순/높은 순), 투자기간 범위 슬라이더(1~12개월+), 모집금액 범위 슬라이더(1만~1억+) |
| 유형 필터 | `?type=scf` / `?type=stock_loan` / `?type=mortgage` / `?type=personal_credit` |
| 카드 필드 | 상품번호·상품명·연수익률·투자기간·모집금액·모집상태·상품유형 배지·특약 태그·진행률%·등록일 |
| 기타 | 마감 상품 섹션 + 더보기, 신규 상품 알림 설정 버튼(로그인) |

### F-INV-02 투자 상품 상세

- 요약 카드: 남은 금액/모집금액·진행률(새로고침)·모집일·연수익률·기간
- 액션: 장바구니 담기 / 예상수익 / 투자하기
- 탭: 상품 종합정보(차입자 실적 표·연체율) / 상세정보(대상지 정보·증빙서류·FAQ 아코디언) / 투자 시 유의사항
- 로그인 시 개인화 블록: 나의 예치금, 투자 가능 금액(등급 한도·동일차주 한도 반영), 충전 링크

### F-INV-03 예상수익 계산기

| 항목 | 내용 |
|---|---|
| 입력 | 투자금액(만원 단위) + 퀵버튼(1,000만/100만/10만원+) |
| 출력 | 모집금액·세전 수익률·세후 수익률·기간 요약 + 회차별 상환 스케줄 표 |
| 표 컬럼 | 회차 / 이자 지급일 / 투자원금 / 상환원금 / 수익금(세전) / 세금 / 플랫폼 이용료 / 수익금(세후) |
| 계산 규칙 | 상환방식별(원리금균등·만기일시·원금균등) 스케줄 생성. 세금 = 이자소득세 14% + 지방소득세 1.4%(합 15.4%), 플랫폼 이용료 상품별 연 % |
| 구현 | 계산 로직의 정본은 BE API. FE는 모달에서 API 호출 결과를 표시 |

### F-INV-04 투자 주문 (핵심)

| 항목 | 내용 |
|---|---|
| 화면 | `/investment/{id}/order` |
| 입력 | 투자 금액(만원), 사용 포인트(선택), '네' 최종 확인 입력 |
| 검증(서버, 단일 트랜잭션) | ①로그인 ②적합성 테스트 유효 ③상품 모집중 ④금액 ≤ min(나의 등급 잔여 한도, 동일차주 잔여 한도, 상품 잔여 모집액) ⑤예치금+사용 포인트 ≥ 투자금액 |
| 멱등성 | 클라이언트가 생성한 멱등 키를 헤더로 전송. 동일 키 재전송 → 기존 주문 결과 반환(신규 생성 없음) |
| 동시성 | 잔여 모집액 차감은 `SELECT ... FOR UPDATE`로 직렬화. 잔액 부족 시 409 |
| 결과 | 투자 건 생성 + 예치금 원장 차감 분개 + 포인트 사용 분개 + 상환 스케줄 생성 |
| 실패 | 한도 초과/잔액 부족/모집 마감 시 사유 코드 반환 |

### F-INV-05 투자적합성 테스트

- 6문항 객관식, 전부 정답 필요. 오답 시 재응시
- 결과 1년 유효. `투자하기` 클릭 시 미통과면 테스트로 강제 이동
- 문항은 서버에서 채점(클라이언트 채점 금지)

### F-INV-06 장바구니

- 담기(상품 상세) / 목록 조회 / 삭제 / 합계 표시. 상품당 1행
- GNB 뱃지에 건수. 담긴 상품이 마감되면 목록에 "마감" 표시
- 일괄 투자 미지원(상품별 주문만)

### F-INV-07 예약 투자 (리파이낸싱 재투자)

- 만기 임박 상품의 기존 투자자에게 "재모집 예약" 신청 화면
- 신규 모집이 열리면 예약분을 우선 투자 주문으로 전환 → 예약자는 이자 지급+원금 재투자, 미예약자는 원리금 상환
- 예약 취소·금액 조정 가능. 예약 실패(모집 미달) 시 원리금 상환으로 폴백

### F-INV-08 상환 처리

- 상환 스케줄: 투자 생성 시 상품의 상환방식에 맞춰 회차별 생성(이자 지급일 = 매월 N일)
- 상환 배치: 지급일에 배치가 원금+이자를 예치금 원장에 반영(세금 15.4%·플랫폼이용료 차감 후 세후 지급)
- 연체: 지급일 초과 시 연체 상태 전환, 연체이자 가산
- 조기상환: 중도상환수수료 차감 후 잔여 스케줄 재계산

## F-DEP 예치금·가상계좌

### F-DEP-01 가상계좌 발급

- 가입 완료 시 회원당 1개 발급: `은행코드 + 계좌번호(일련 규칙)`
- 대시보드에서 계좌 정보(예금주/은행/계좌번호) + 복사 버튼

### F-DEP-02 입금 (모의 은행 웹훅)

| 항목 | 내용 |
|---|---|
| 흐름 | 사용자가 "입금 알리기"(예금주명·금액) → 모의 은행 모듈이 입금 완료 웹훅을 API로 POST → 서명(HMAC) 검증 → 가상계좌 매칭 → 원장 입금 분개 → 잔액 갱신 |
| 매칭 | 예금주명 불일치 → 보류 큐, 운영자 수동 매칭. 금액 제한(최소 1원·1회 한도) |
| 멱등 | 웹훅 `event_id`로 중복 수신 무시 |
| 상태 | 입금 요청 pending → 웹훅 수신 credited / 보류 held |

### F-DEP-03 출금

- 입력: 출금 금액(전액출금 체크) → 비밀번호 재확인(F-AUTH-05) → 출금 요청
- 정책: 출금 가능액 = 예치금 − 홀드 중 금액. 수수료 월 20회 면제·21회부터 건당 500원
- 상태머신: requested → processing(모의 은행 이체) → completed / failed(롤백 분개)
- 1일 출금 한도

### F-DEP-04 예치금 원장

- 모든 잔액 변경은 원장 분개로만 발생: 입금, 출금 홀드/확정, 투자 차감, 상환 입금, 포인트 전환, 수수료
- 계정과대: `예치금(사용자)` ↔ `청산(모의 은행)` / `투자금(상품별)` / `수익금` / `수수료수입` / `포인트부채`
- 원장 불변식: 분개당 차대 합계 0, 잔액 = 분개 합계. 일일 대사 배치로 검증

### F-DEP-05 연결계좌·간편충전

- 연결계좌 등록(출금 수령 계좌, 본인명의 검증 모의)
- 간편충전 ON/OFF: ON이면 투자 시 부족분을 연결계좌에서 자동 입금 처리(모의 은행 즉시 이체 웹훅 발생)

## F-PNT 포인트

### F-PNT-01 포인트 원장

- 적립(가입·이벤트·추천인·상환 보너스) / 사용(투자 사용 = 예치금 전환) / 소멸(유효기간 만료) 분개
- 소멸 배치: 매월 1일 만료분 소멸, `당월 소멸 예정 포인트` 조회
- 투자 사용 시 분개: 포인트부채 차감 → 예치금 가산(전환)

### F-PNT-02 포인트 내역

- 보유 포인트, 당월 소멸 예정, 기간 조회, 엑셀 저장(CSV 다운로드)

## F-MY 마이페이지

### F-MY-01 대시보드

- 프로필(이름·이메일·등급·본인인증 상태), 가상계좌 정보 + 복사
- 내 예치금 + 충전하기/출금하기, 내 포인트(전환/적립)
- 남은 투자한도(부동산 한도/총 한도), 총 투자금액
- 투자 중 집계(투자금액·투자잔액·누적 수익 세후·잔여 예상 수익 세후), 지난 투자 집계
- 대출자 전환 숏컷, 개인정보 변경, 등급 변경 신청, 계좌관리

### F-MY-02 상환달력

- 월 이동 캘린더, 일자별 상환 예정/완료 표시
- 월 집계: 총 상환 원금(완료/예정), 총 상환 이자(완료/예정), 세후 기준

### F-MY-03 투자내역

- 필터: 전체/진행중/상환완료/연체/손실 + 유형(부동산/동산/개인신용), 건수 뱃지
- 건별 상세: 상품 정보, 투자금액, 회차별 상환 현황, 누적 수익

### F-MY-04 예치금내역

- 기간 퀵버튼(1주일/1개월/3개월/6개월) + 기간 조회, 더 보기
- 탭: 예치금 내역 / 원천징수영수증 / 플랫폼 이용료 내역

### F-MY-05 등급 관리

- 등급: 일반투자자 / 소득적격투자자 / 전문투자자
- 한도 규칙(실서비스 기준): 일반 — 총 4,000만·부동산 2,000만·동일차주 500만 / 소득적격 — 총 1억·부동산 1억·동일차주 2,000만 / 전문 — 총 무제한·상품별 최대 40%
- 등급 변경 신청 → 자격 요건 충족 표시 → 서류 제출(원스톱 한도심사 모의: 파일 업로드) → 운영자 승인 → 등급 반영. 변경 이력 조회

## F-LOAN 대출

### F-LOAN-01 대출 상품 목록

- 탭: 전체 / 개인대출 / 기업대출
- 카드: 상품명·대상·한도·금리 범위·기간·상환방식

### F-LOAN-02 대출 상품 상세

- 특장점, 대출 절차 STEP(신청→서류 심사→전자계약→모집·실행), 상품 안내 표(금리·한도·기간·상환방식·중도상환수수료·연체금리·부대비용), 유의사항, FAQ 아코디언, 신청 CTA, 상담 버튼

### F-LOAN-03 간편 한도 조회 (모의)

- 입력: 단지명·면적·동/호(아파트담보) 또는 사업자 정보(신용)
- 결과: 모의 한도·금리 산출 → 사전심사 신청 CTA. "신용도에 영향 없음" 안내

### F-LOAN-04 대출 신청

- 1/2 기본 정보: 이름·연락처·이메일·회사명·사업자 유형·사업자번호 + 개인정보 동의(필수)/마케팅(선택)
- 2/2 자금 정보: 필요자금·기간·용도·요청내용·첨부파일(최대 6개)
- 제출 후 운영자 심사 큐에 등록. 승인 시 투자 상품으로 전환(운영자 기능)

## 공통 규칙

- **금액**: 전부 정수(원) 또는 DecimalField(18,2)로 저장, 부동소수점 금지
- **멱등 키**: 투자·출금·포인트 전환 등 부수효과 POST는 `Idempotency-Key` 헤더 필수
- **에러 코드**: `{ code, message, details }` 일관 형식
- **시간**: 서버 UTC 저장, 표시는 KST
- **모의 표기**: 본인인증·은행 이체·심사는 UI에 "시뮬레이션" 배지를 붙여 실제 연동이 아님을 명시
